# 🍉 수박 게임 (Suika Game) - 진화 가이드 포함판

웹 표준 기술(HTML5, CSS3, JavaScript)과 2D 물리 엔진 라이브러리인 **Matter.js**를 활용하여 구현한 클래식 수박 게임입니다. 마우스나 터치 조작을 통해 같은 과일을 합쳐가며 최종 단계인 '수박'을 만드는 것이 목표입니다.

---

## 🎮 게임 플레이 방법 (Play Guide)

### 1. 기본 규칙
* 화면 상단에 스폰되는 과일을 원하는 위치에 떨어뜨립니다.
* **동일한 종류(레벨)의 과일** 두 개가 서로 부딪히면, 두 과일이 합쳐지며 **한 단계 더 큰 과일로 진화**하고 점수를 획득합니다.
* 과일이 계속 쌓여 화면 상단의 **붉은색 데드라인(Dead Line)**을 넘은 상태로 3초 이상 유지되면 게임 오버(Game Over)가 됩니다.

### 2. 조작 방법
* **PC (마우스):** 마우스를 좌우로 움직여 과일 위치를 조작하고, **클릭(Left Click)**하여 과일을 아래로 떨어뜨립니다.
* **Mobile (터치):** 화면을 터치한 채 좌우로 드래그하여 위치를 조작하고, **손가락을 떼면(Touch End)** 과일이 떨어집니다.

## ✨ 핵심 핵심 기능 & 시스템 (Key Features)

* **Matter.js 물리 시뮬레이션:** 중력, 탄성 충돌, 마찰력 등 정교한 2D 물리 법칙이 적용되어 과일이 부딪히고 미끄러지는 현실적인 움직임을 제공합니다.
* **연속 콤보(Combo) 시스템:** 과일이 합쳐진 후 2.5초 이내에 또 다른 진화가 일어나면 콤보가 발동하여 **추가 보너스 점수**를 획득합니다.
* **인간적 게임 오버 유예 판정:** 과일이 데드라인을 밟자마자 게임이 끝나는 것이 아니라, 고유 타임스탬프 로직을 통해 `3초` 동안 선 위에 머물러 있을 때만 최종 게임 오버가 선언됩니다.
* **반응형 가이드 UI:** 레벨별 가중치를 둔 선형 증폭 공식(`8 + (level * 2.2)`)을 도입하여, 가이드 보드 내에서 체리와 수박의 크기 격차를 시각적으로 명확하게 구분했습니다.
